I'm a software developer based in Kandy, Sri Lanka, focused on building practical, well-crafted applications — both for the web and the desktop.

My work spans from full-featured web systems (HR management, booking platforms, dashboards) to Java Swing desktop apps, and everything in between. I care about code that's readable, UIs that feel natural, and software that genuinely helps people.

I'm especially experienced in building Sri Lanka–context software — systems that understand local labour law (EPF/ETF compliance), local business workflows, and the Sinhala language where needed.

I enjoy the full journey — from architecting a system to the final pixel of the UI. My stack is flexible, but my standards aren't.
